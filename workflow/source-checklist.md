# Source Checklist

Before including any source in a story's citation list, run it through
this checklist. If it fails any "must" item, drop that source — never
include it just to hit the 3–5 source target.

## Must-haves
- [ ] Source is a named, identifiable outlet (not "search results" or a
      generic aggregator)
- [ ] Source is on the preferred list (`resources/preferred-sources.md`)
      OR is a well-known, reputable outlet not on the excluded list
- [ ] Story has a clear, verifiable publish/update date
- [ ] A direct working link to the original article exists
- [ ] Source is not on the excluded list (`resources/excluded-sources.md`)

## Strongly preferred
- [ ] Source is a primary source (official statement, direct reporting)
      rather than a secondary summary of someone else's reporting
- [ ] Outlet has a track record of factual accuracy (avoid outlets known
      for frequent corrections/retractions on major stories)
- [ ] Source has a listed bias/lean in
      `resources/source-bias-ratings.md` (if not, mark as "Unrated" rather
      than guessing)

## Independence check (new — required for multi-source stories)
- [ ] Confirm the source is independently reported, not a verbatim
      republish/syndication of another outlet already counted (e.g. a
      local paper's word-for-word AP reprint doesn't count as a second
      independent source alongside AP itself)
- [ ] If two sources share the same underlying wire report, count them as
      one source in the 3–5 total, but it's fine to link both if useful

## Red flags — exclude if present
- Anonymous or unattributed authorship with no editorial backing
- Content-farm or SEO-only site with no original reporting
- Unverified social media posts as the sole source
- Satire or opinion presented as straight news
- Conflicting dates across sources with no way to resolve which is correct

## When in doubt
If a story seems important but few credible sources exist, that's fine —
report it with what's available and note the limited coverage explicitly
in the story summary (per CLAUDE.md Rule 3). Never substitute a
lower-quality source just to reach the 3–5 target.
