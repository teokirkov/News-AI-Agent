# Bias & Multi-Source Synthesis Guide

How to turn 3–5 separate source reports into one coherent, neutral story
summary — while still surfacing useful bias context for the reader.

---

## The core principle
The **summary narrative** stays neutral and fact-focused, written in
Claude's own words. **Bias context lives in the citation list and, when
relevant, in a short framing note** — it's not woven into the main
narrative as commentary.

## Step-by-step synthesis process

1. **Read all gathered sources for the story first**, noting:
   - Facts that are consistent across all/most sources (the reliable core)
   - Facts reported by only one source (flag as less-corroborated if used)
   - Any direct factual contradictions between sources
   - Differences in framing/emphasis (not fact, but angle)

2. **Write the summary from the consistent core facts.**
   - What happened, who's involved, why it matters.
   - 3–6 sentences, neutral tone, original wording (never copy phrasing
     from any single source).

3. **Handle factual disagreements explicitly.**
   - If sources disagree on a material fact (e.g. casualty counts, quoted
     figures, attributed causes), say so plainly:
     > "Casualty estimates vary by source, ranging from X to Y."
   - Don't silently pick the version from your "preferred" source — surface
     the discrepancy.

4. **Handle framing differences with a short, neutral note (optional, only
   if genuinely notable).**
   - Example: "Coverage frames the policy's economic impact differently:
     outlets on the right emphasize projected cost savings, while outlets
     on the left emphasize potential service cuts — the underlying policy
     details are consistent across all reports."
   - Don't do this for every story — only when framing differences are
     substantial enough to be useful context, not just stylistic.

5. **Check for lopsided coverage.**
   - If all 3–5 sources share a similar editorial lean (per
     `resources/source-bias-ratings.md`), note it:
     > "Note: coverage of this story currently skews toward
     [left/right/wire]-leaning outlets; limited reporting found from
     other perspectives as of publish time."
   - This is descriptive, not a criticism of the story's validity — just
     transparency about the current media landscape on that topic.

6. **Build the citation list.**
   - One line per source: `Outlet — Lean — [link] — Date`
   - List sources in a consistent order (e.g. wire services first, then
     alphabetical, or by lean spread) — pick one convention and keep it
     consistent across the report.

## What NOT to do
- Don't let the summary itself lean toward any single source's framing.
- Don't omit a source's lean because it's inconvenient — always report
  known leans plainly, or mark "Unrated" if unknown.
- Don't manufacture a "balanced" summary by cherry-picking equal amounts
  from left- and right-leaning sources if the underlying facts aren't
  actually in dispute — synthesize the facts first, bias-check second.
- Don't present bias ratings as objective, precise scores — they're a
  general reference (see `resources/source-bias-ratings.md` for caveats),
  not a scientific measurement.

## Quick template for a framing/coverage note (use only when relevant)
> "Coverage note: [what varies — facts, framing, or lopsided lean] — [one
> sentence of neutral context]."
